What this experiment can establish

Mechanism evidence

A result supports or weakens an allocation rule under explicitly modeled worker differences, feedback, switching costs, and progress dynamics. New evaluation seeds test repeatability. Structural holdouts test changes absent from tuning.

Salary balances redistribute an existing budget. They do not create compute or train model weights. If a conventional revised scheduler wins, currency is not shown to be necessary.

What still needs real-world evidence

Model behavior, verification reliability, actual memory transfer, API cost, latency, integration effort, and willingness to pay require real workloads. A synthetic benefit is not a commercial forecast.

Economic survival, bandit allocation, pruning, and memory have prior art. Read the source-backed novelty and product assessment.

Statistical method and reproducibility

Before evaluation, the documented audit strengthened UCB with continuation leases and added explore-commit and a shared-progress null. Outside that null, worker progress is private and concentration can help by construction. Offline tuning costs and unequal candidate counts are separate from charged online overhead.
